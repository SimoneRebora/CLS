The fourth chapter explores the connections between thematic criticism and topic modeling. The accompanying page contains a list of tools and resources for topic modeling.

## LDA Topic Modeling

### [Mallet](https://mimno.github.io/Mallet/)

![Screenshot of Mallet]({{ '/assets/images/TopicModeling_1.png' | relative_url }})

MALLET is a Java-based package for statistical natural language processing, document classification, clustering, topic modeling, information extraction, and other machine learning applications to text.  
***More info [here](https://mimno.github.io/Mallet/)***

### [jsLDA](https://mimno.infosci.cornell.edu/jsLDA/jslda.html)

![Screenshot of jsLDA]({{ '/assets/images/TopicModeling_2.png' | relative_url }})

The goals of this project are to (a) make running topic models easy for anyone with a modern web browser, (b) demonstrate the potential of statistical computing in Javascript and (c) allow tighter integration between models and web-based visualizations.  
***More info [here](https://mimno.infosci.cornell.edu/jsLDA/jslda.html)***

### [TopicsExplorer](https://dariah-de.github.io/TopicsExplorer/)

![Screenshot of TopicsExplorer]({{ '/assets/images/TopicModeling_3.png' | relative_url }})

This application provides a simple and intuitive interface for exploring your own text corpus using latent Dirichlet allocation, one of the most popular topic models.  
***More info [here](https://dariah-de.github.io/TopicsExplorer/)***

## Other Topic Modeling Approaches

### [IRaMuTeQ](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/)

![Screenshot of IRaMuTeQ]({{ '/assets/images/TopicModeling_4.png' | relative_url }})

Free software for multiple types of text analysis. It includes the Reinert method.  
***More info [here](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/)***

### [BERTopic](https://maartengr.github.io/BERTopic/)

![Screenshot of BERTopic]({{ '/assets/images/TopicModeling_5.png' | relative_url }})

BERTopic is a topic modeling technique that leverages 🤗 transformers and c-TF-IDF to create dense clusters allowing for easily interpretable topics whilst keeping important words in the topic descriptions.  
***More info [here](https://maartengr.github.io/BERTopic/)***
