The fifth chapter focusses on GIS technology and spatial literary studies. The accompanying page contains a list of tools and resources for mapping.

## Mapping Environments

### [Recogito](https://recogito.pelagios.org/)

![Screenshot of Recogito]({{ '/assets/images/Mapping_1.png' | relative_url }})

An open online platform for text annotation. It allows to easily create a map from an annotated text, by relying on multiple historical gazetteers.  
***More info [here](https://recogito.pelagios.org/)***

### [QGIS](https://www.qgis.org/)

![Screenshot of QGIS]({{ '/assets/images/Mapping_2.png' | relative_url }})

A free software for professional map creation. It comes with a rich graphical interface  
***More info [here](https://www.qgis.org/)***

### [Leaflet](https://leafletjs.com/)

![Screenshot of Leaflet]({{ '/assets/images/Mapping_3.png' | relative_url }})

An open-source JavaScript library for mobile-friendly interactive maps. It requires basic programming skills, and can also be used [via the R programming language](https://cran.r-project.org/web/packages/leaflet/index.html)  
***More info [here](https://leafletjs.com/)***

### [Carto](https://carto.com/)

![Screenshot of Carto]({{ '/assets/images/Mapping_4.png' | relative_url }})

A commercial platform for interactive map creation. Easy to use, it comes with an intuitive grapical interface  
***More info [here](https://carto.com/)***

## Mapping Resources

### [geojson.io](https://geojson.io/)

![Screenshot of geojson.io]({{ '/assets/images/Mapping_5.png' | relative_url }})

An online free tool to manually create/modify geojson files (containing geocoded shapes)  
***More info [here](https://geojson.io/)***

### [Map Warper](https://mapwarper.net/)

![Screenshot of Map Warper]({{ '/assets/images/Mapping_6.png' | relative_url }})

An online free tool to warp historical maps over geocoded locations  
***More info [here](https://mapwarper.net/)***
