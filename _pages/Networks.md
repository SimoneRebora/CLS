The sixth chapter connects character studies and social network analysis. The accompanying page contains a list of tools and resources for network analysis.

## Network Analysis Tools

### [Gephi](https://gephi.org/desktop/)

![Screenshot of Gephi]({{ '/assets/images/Networks_1.png' | relative_url }})

An open-source desktop application to visually analyze networks.  
***More info [here](https://gephi.org/desktop/)***

### [Gephi Lite](https://lite.gephi.org/v1.0.2/)

![Screenshot of Gephi Lite]({{ '/assets/images/Networks_2.png' | relative_url }})

The online version of Gephi. Lighter and simpler, it does not require installation.  
***More info [here](https://lite.gephi.org/v1.0.2/)***

### [igraph](https://igraph.org/)

![Screenshot of igraph]({{ '/assets/images/Networks_3.png' | relative_url }})

A collection of network analysis tools with the emphasis on efficiency, portability and ease of use. Open source and free, igraph can be used in R, python, Mathematica, and C/C++  
***More info [here](https://igraph.org/)***

### [NetworkX](https://networkx.org/)

![Screenshot of NetworkX]({{ '/assets/images/Networks_4.png' | relative_url }})

A Python package for the creation, manipulation, and study of the structure, dynamics, and functions of complex networks.  
***More info [here](https://networkx.org/)***
