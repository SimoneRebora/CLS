## Tools

### [Stylo](https://github.com/computationalstylistics/stylo)

![Screenshot of Stylo]({{ '/assets/images/Stylometry_2.png' | relative_url }})

A user-friendly tool to run multiple stylometric analyses.  
***More info [here](https://github.com/computationalstylistics/stylo)***

### [JGAAP](https://evllabs.github.io/JGAAP/)

![Screenshot of JGAAP]({{ '/assets/images/Stylometry_3.png' | relative_url }})

An advanced tool for authorship attribution.  
***More info [here](https://evllabs.github.io/JGAAP/)***

### [PyDelta](https://github.com/fotisj/pydelta)

![Screenshot of PyDelta]({{ '/assets/images/Stylometry_4.png' | relative_url }})

An experimental implementation of Burrow's delta in Python 3.  
***More info [here](https://github.com/fotisj/pydelta)***
